1. Executive Summary

Apivexo is a full-featured, multi-language online gaming platform designed for the South Asian market, with primary support for Bangladesh (BDT) and India (INR). The client application is a modern, responsive web platform built on Next.js 16 and React 19, delivering a premium casino, sports betting, and entertainment experience accessible from desktop and mobile browsers.

2. Platform Architecture Overview

Technology Stack

Next.js 16 (App Router) React 19 TypeScript Tailwind CSS 4 Socket.IO Client FingerprintJS

Application Structure

The Apivexo client follows a locale-first routing architecture. All user-facing pages are prefixed with a language code (/en, /bn, /hi), enabling seamless multilingual navigation without separate deployments.

Route Group Access Level Description
/(site) Public Home page, game lobbies, promotions, VIP, referral landing
/(auth) Public Login, registration, forgot password
/member/* Authenticated Member center, wallet, rewards, profile, records (auth-guarded)
/api/* Internal Game launch proxy and backend API gateway

Core Design Principles

  • Mobile-first responsive design — Optimized for smartphones with dedicated bottom navigation and touch-friendly controls.
  • Server-side rendering — Game lobbies and public pages are server-rendered for SEO and fast initial load.
  • Secure session management — JWT-based authentication with automatic session expiry and balance synchronization.
  • Modular component architecture — Feature domains are isolated into reusable component libraries with dedicated API layers.
  • Localized content catalogs — 31 dedicated translation modules ensure consistent multilingual UX across all features.

4. Authentication & Account Security

User Login Live

Secure username and password authentication with device fingerprint collection for fraud prevention. Supports redirect to intended destination via ?next= URL parameter. Handles forced password change flows and displays localized error messages.

Route: /[locale]/login

Three-Step Registration Live

Guided registration wizard: Step 1 — phone number with country-specific formatting (BDT/INR); Step 2 — username selection; Step 3 — password creation with strength validation. Supports referral code capture from URL parameters, device registration limit enforcement, and automatic login upon successful signup.

Route: /[locale]/register · Referral param: ?refId= or ?ref=

Forgot Password Live

Self-service password recovery requiring username, registered phone number, and new password with validation rules. Submits reset request to the backend API for verification and update.

Route: /[locale]/forgot-password

Change Password Live

Authenticated password change with real-time validation enforcing minimum length, uppercase letter, numeric digit, and special character requirements. Accessible from the Security Center in Member Center.

Route: /member/login-security/change-password

Session Management Live

JWT-based session stored securely in browser local storage with automatic expiry detection, balance synchronization with server revision tracking, account status validation (active/restricted), and auth guard protection on all member-area routes.

Personal Information Management Live

Tabbed profile hub for managing full legal name, date of birth, phone number, and email address. Phone and email updates include OTP verification flows. Privacy notice displayed on all personal information pages.

Routes: /member/personal-info/* (full-legal-name, date-of-birth, phone, email + verify pages)

KYC Document Verification Live

Identity verification module allowing users to upload government-issued documents for account verification. Supports document type selection and secure file upload to the backend KYC service.

Route: /member/verification/documents

Account Status Enforcement Live

Platform-wide account restriction system that blocks game play, withdrawals, and other sensitive actions based on account status (active, suspended, restricted). Displays localized restriction messages explaining the limitation to the user.

Game Launch System

Game Play Gate Live

Comprehensive pre-launch validation system triggered when a user clicks any game card:

  • Authentication check — prompts login modal for unauthenticated users
  • Zero-balance block — prevents launch when wallet balance is insufficient
  • Account restriction check — blocks play for restricted/suspended accounts
  • Balance preview — displays current balance before launch confirmation
  • Eligibility API validation — server-side check for game access permissions
  • Launch overlay — loading state during game initialization
  • Platform detection — sends mobile (platform=2) or desktop (platform=1) flag to game provider
  • Return handler — automatic balance refresh and vendor transaction sync when returning from a game

7. Wallet, Deposits & Withdrawals

Real-Time Wallet Balance Live

Live wallet balance display in the top navigation bar and member center with hide/show privacy toggle, manual refresh action, VIP points display, and local state synchronization with server revision tracking to prevent stale balance display.

Deposit Hub Live

Central deposit method selection screen. Currently active: Quick Deposit (mobile financial services). Additional methods (E-wallet, Cryptocurrency, Local Bank Transfer) are architecturally prepared for future activation.

Route: /member/deposit

Quick Deposit Live

Streamlined deposit flow for Bangladesh mobile financial services. Users select payment method (bKash, Nagad, or Rocket), choose a payment channel/account, enter deposit amount, optionally select a deposit promotion/bonus, preview bonus calculation, and proceed to payment verification.

Route: /member/deposit/quick · Methods: bKash, Nagad, Rocket

Deposit Payment Verification Live

Payment instruction page displaying the assigned payment account details with copy-to-clipboard functionality. Features countdown timers (10-minute payment window, 3-minute verification window), transaction ID submission, automatic payment verification polling, manual deposit fallback, duplicate transaction ID detection, and bonus confirmation messaging.

Route: /member/deposit/quick/verify

Deposit Promotion Picker Live

Integrated bonus selection during the deposit flow. Users can choose from available deposit promotions and see a real-time preview of the bonus amount before confirming the deposit.

Withdrawal Live

Withdrawal submission form allowing users to select a saved payout wallet (bKash, Nagad, Rocket), enter withdrawal amount (minimum 100), and submit the request. Includes account status validation, insufficient balance checks, and redirect to add-wallet page if no payout wallets are configured.

Route: /member/withdraw

Payout Wallet Management Live

Add and manage payout wallets for withdrawals. Users can register wallets with holder name and account number for bKash, Nagad, and Rocket. Supports adding up to the maximum allowed wallets and deleting existing ones.

Route: /member/add-wallet

Transaction Records Live

Comprehensive transaction history with filtering by status, payment type, and date range. Separate views for deposit records, withdrawal records, and general account records. Includes detail modals for individual transaction inspection.

Route: /member/transaction-records

16. Mobile Experience & App Distribution
